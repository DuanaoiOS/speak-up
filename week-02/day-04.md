# Week 2 Day 4: 推测与假设

> 今日目标：自然地表达推测、假设和可能性，不只是 "maybe" 和 "perhaps"

---

## 一、句型框架（15 分钟）

### 句型 1：If I had to guess, I'd say [speculation].

**用在哪**：没有确切答案时的推测。比 "maybe" 完整，比 "I think" 更谨慎。

**例句**：If I had to guess, I'd say most people spend about 3 hours a day on their phone without even realizing it.

**轮到你**：
1. 关于未来 10 年的变化：If I had to guess, I'd say _____.
2. 关于为什么很多人学不好英语：If I had to guess, I'd say _____.
3. 关于你的朋友现在在做什么：If I had to guess, I'd say _____.
4. 你的推测：If I had to guess, I'd say _____.

### 句型 2：Chances are [likely outcome].

**用在哪**：表达"大概率会发生的事"。比 "probably" 更地道。

**例句**：Chances are if you practice speaking every day for a month, you'll notice a huge difference.

**轮到你**：
1. Chances are **if you keep putting off practice, you'll never get better.**
2. Chances are **the person you're talking to also feels nervous about speaking English.**
3. Chances are **in 10 years, AI will _____ .**
4. Chances are _____.

### 句型 3：What if [hypothetical scenario]? [Imagine the implications].

**用在哪**：提出一个假设，引发思考或讨论。

**例句**：What if we could learn languages as easily as uploading a file to our brain? Would we still value the process of learning, or would something be lost?

**轮到你**：
1. What if **humans could live to 150**? _____
2. What if **social media suddenly disappeared tomorrow**? _____
3. What if **you could only speak one language for the rest of your life**? _____
4. What if _____? _____

## 二、搭配爆破（10 分钟）

| 中文 | 英文 |
|------|------|
| 很有可能 | it's highly likely that... / odds are... |
| 不太可能 | it's unlikely that... / fat chance |
| 我敢打赌 | I bet... / I'm willing to bet that... |
| 谁知道呢 | who knows? / your guess is as good as mine |
| 假设...的话 | let's say... / suppose... / assuming that... |
| 最好的情况/最坏的情况 | best-case scenario / worst-case scenario |
| 只是时间问题 | it's only a matter of time |
| 出乎意料 | against all odds / nobody saw that coming |
| 预感 | I have a hunch that... / gut feeling |
| 拭目以待 | we'll see / time will tell / let's wait and see |

## 四、即兴表达（15 分钟）

**话题**：What do you think the world will look like in 20 years?

用推测和假设的句型，不要只给出"确定"的答案。聊聊几种可能性、最好和最坏的情况，以及一个"如果...会怎样"的脑洞。

**准备**（1 分钟，提示词）：

If I had to guess... / Chances are... / Best-case scenario... / Worst-case scenario... / What if...? / It's only a matter of time before...

**开始**：录音，说 1-2 分钟。尽情推测，不需要"正确答案"。

**回听**：
- [ ] 有没有用多种推测表达，而不是一直 "will"？
- [ ] 有没有区分"确定的预测"和"纯脑洞"？（语调要不同）
- [ ] 有没有一个"如果...会怎样"的好问题？

**修正**：找到最不确定的那段，用 If I had to guess 重新表达。
