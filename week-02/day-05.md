# Week 2 Day 5: 总结与结论

> 今日目标：有力地把观点收拢，不虎头蛇尾地结束

---

## 一、句型框架（15 分钟）

### 句型 1：At the end of the day, [core message / bottom line].

**用在哪**：抛开所有细节，说出最核心的那句话。非常有说服力。

**例句**：At the end of the day, it doesn't matter which method you use — what matters is that you show up every day.

**轮到你**：
1. 关于学英语：At the end of the day, _____.
2. 关于职业选择：At the end of the day, _____.
3. 关于人际关系：At the end of the day, _____.
4. 你最近在思考的事：At the end of the day, _____.

### 句型 2：So what I'm trying to say is [distilled point].

**用在哪**：感觉自己说了很多，用这句话把最核心的意思提炼出来。

**例句**：So what I'm trying to say is, we need to stop treating speaking as a test and start treating it as a skill.

**轮到你**（把复杂的想法浓缩成一句）：
1. 关于为什么 CET-6 的人说不出英语 → So what I'm trying to say is, _____.
2. 关于社交媒体的影响 → So what I'm trying to say is, _____.
3. 关于你的人生哲学 → So what I'm trying to say is, _____.

### 句型 3：The bottom line is [most important point]. Everything else is secondary.

**用在哪**：最强力的总结，用于定调。"其他的都不重要，这才是最关键的。"

**例句**：The bottom line is you have to speak to get better at speaking. Everything else — textbooks, apps, grammar exercises — is secondary.

**轮到你**：
1. The bottom line is **practice beats theory every time.** Everything else is secondary.
2. 关于健康：The bottom line is _____. Everything else is secondary.
3. 关于幸福：The bottom line is _____. Everything else is secondary.
4. 关于你坚信的一件事：The bottom line is _____. Everything else is secondary.

## 二、搭配爆破（10 分钟）

| 中文 | 英文 |
|------|------|
| 总而言之 | to sum up / all in all |
| 归根结底 | when it comes down to it / ultimately |
| 这让我想到 | this brings me to my point / which leads me to... |
| 最关键的是 | the key takeaway is... / if there's one thing to remember... |

## 四、即兴表达（15 分钟）

**话题**：What's one piece of advice you would give to your younger self?

用完整的论证结构来回答：观点 → 解释 → 例子 → 总结。最后用今天学的总结句型收尾。

**准备**（1 分钟，提示词）：

If I could go back, I would tell myself... / What I mean is... / A good example is... / At the end of the day... / The bottom line is...

**开始**：录音，说 1-2 分钟。关键是最后 30 秒的总结要有力，不要"嗯...就这些吧"。

**回听**：
- [ ] 有没有一个清晰的结论句？
- [ ] 结论是不是只重复了开头？还是真的总结/升华了？
- [ ] 最后的落点有没有力度？（At the end of the day / The bottom line is）

**修正**：把最后 30 秒的总结重新说 3 遍，确保干脆有力，不拖拉。
