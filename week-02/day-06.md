## 一、句型极速反应（15 分钟）

**规则**：看提示，3 秒内说出完整句子。超时 = 标记，全部测完重练。

### 第一轮：同意与不同意

| 情境 | 你的回答（出声） | ✓ |
|------|-----------------|---|
| 有人说了你完全同意的观点 | I totally agree. I mean... | |
| 你不完全同意，先承认对方有道理 | I see what you mean, but... | |
| 正式场合表达不同意见 | That's a fair point, although I'd say... | |
| 部分同意部分不同意 | I partly agree. On the one hand... | |

### 第二轮：解释与举例

| 情境 | 你的回答 | ✓ |
|------|---------|---|
| 你说了一个抽象观点，需要解释 | What I mean by that is... | |
| 需要用一个具体例子支撑 | A good example of this is... | |
| 用一个类比让人秒懂 | It's like... | |
| 用一个典型例子证明观点 | Take... for example. | |

### 第三轮：对比与比较

| 情境 | 你的回答 | ✓ |
|------|---------|---|
| 对比现在和过去 | Compared to..., ... is... | |
| 指出核心差异 | The main difference is... whereas... | |
| 承认相似再说不同 | They're similar in that..., but... | |
| 各有优劣 | Each has its pros and cons. | |

### 第四轮：推测与假设

| 情境 | 你的回答 | ✓ |
|------|---------|---|
| 给出一个推测 | If I had to guess, I'd say... | |
| 说某事很有可能 | Chances are... | |
| 提出一个脑洞假设 | What if...? | |
| 说某事只是时间问题 | It's only a matter of time before... | |

### 第五轮：总结与结论

| 情境 | 你的回答 | ✓ |
|------|---------|---|
| 抛开细节说核心 | At the end of the day,... | |
| 浓缩复杂度为一句话 | So what I'm trying to say is... | |
| 说最重要的那条信息 | The bottom line is... | |
| 你的完整论证框架 | 观点→解释→例子→反驳→总结 | |

## 三、即兴表达挑战（20 分钟）

**规则**：下面 2 个话题，准备 30 秒，说 2 分钟（比上周多了 1 分钟）。必须用到**至少 3 个不同的论证环节**（观点、解释、举例、对比、推测、总结）。

**话题 1**：Is technology making us more connected or more isolated?

**话题 2**：What's one thing you strongly believe that most people around you don't agree with?

每个话题录完回听再进入下一个。

**回听检查**：
- [ ] 2 分钟内有没有清晰的结构？
- [ ] 有没有用具体的例子/类比？
- [ ] 有没有强力的总结句？
- [ ] 说服力如何？你自己被自己说服了吗？
