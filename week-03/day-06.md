## 一、句型极速反应（15 分钟）

**规则**：看情境提示，3 秒内说出完整句子。

### 第一轮：搭建场景

| 情境 | 你的回答 | ✓ |
|------|---------|---|
| 开启一个关于过去的回忆 | This goes back to... | |
| 让听众"看到"画面 | Picture this: ... | |
| 给出必要的背景信息 | The thing you have to understand is... | |

### 第二轮：时间顺序

| 情境 | 你的回答 | ✓ |
|------|---------|---|
| 开始vs转折 | At first... but then... | |
| 事情发生得很快 | Before I knew it,... | |
| 突然发生戏剧性事件 | The next thing I knew,... | |
| 终于/到头来 | Eventually,... | |

### 第三轮：细节与感受

| 情境 | 你的回答 | ✓ |
|------|---------|---|
| 当时的感受+内心独白 | I remember feeling... I remember thinking, "..." | |
| 一个打动你的感官细节 | The thing that struck me was... | |
| 顿悟时刻 | That's when I realized... | |
| 身体反应 | My heart was racing. / I froze. | |

### 第四轮：变化与转折

| 情境 | 你的回答 | ✓ |
|------|---------|---|
| 过去vs现在 | I used to... but now I... | |
| 改变的催化剂 | Everything changed when... | |
| 回头看的反思 | Looking back, I realize... | |

### 第五轮：反思与收获

| 情境 | 你的回答 | ✓ |
|------|---------|---|
| 从经历中学到的 | What I took away from that was... | |
| 如果能重来 | If I could go back, I would... | |
| 教给我的道理 | It taught me that... | |

> 统计：过关 _____ / 15

## 二、即兴表达挑战（25 分钟）

**规则**：下面 3 个话题，每个准备 30 秒，说 2 分钟。每个都必须有完整的叙事弧线。

**话题 1**：Tell me about a trip that didn't go as planned.

**话题 2**：Tell me about someone who changed the way you think about something.

**话题 3**：Tell me about a time you had to do something you were afraid of.

每个话题录完回听再进入下一个。

**回听检查**：
- [ ] 每个故事都有"前→中→后"的完整结构？
- [ ] 至少用了 1 个感官细节？
- [ ] 有"反思/收获"的结尾？
- [ ] 有没有过度使用 "and then"？
