# Week 4 Day 1: 电话与消息

> 今日目标：能自然地打电话和发语音消息，不像是"读电话用语手册"

---

## 一、句型框架（15 分钟）

### 句型 1：I'm calling about [the reason]. / Just following up on [previous topic].

**用在哪**：打电话/语音的开场——一句话说清目的。

**例句**：Hey, I'm calling about the meeting next Tuesday. Just wanted to confirm the time.

**轮到你**（模拟真实打电话场景）：
1. I'm calling about **the reservation I made online. I want to...**
2. I'm calling about **the job application I sent last week. I was wondering if...**
3. Just following up on **that email I sent. Did you get a chance to...**
4. 你自己的场景：I'm calling about _____. / Just following up on _____.

### 句型 2：Could you [request]? / Would it be possible to [polite request]?

**用在哪**：电话中提请求。Could you 是日常用法，Would it be possible to 更正式。

**例句**：Could you send me the details by email? / Would it be possible to reschedule our call to Thursday?

**轮到你**：
1. Could you **repeat that? The line is a bit choppy.**
2. Could you **put me through to the HR department?**
3. Would it be possible to **get a refund?**
4. Would it be possible to _____?

### 句型 3：Let me just [confirm / check / make sure I got this right]. So [summary].

**用在哪**：确认你听懂了对方的意思。这是好电话沟通者的核心习惯。

**例句**：Let me just make sure I got this right. So you need the report by Friday noon, and it should include the Q2 numbers. Is that correct?

**轮到你**（对方说了以下内容后，你来确认）：
1. 对方说了一个地址和见面时间 → Let me just confirm. So _____.
2. 对方解释了一个问题的处理方式 → Let me make sure I got this right. So _____.
3. 你自己的想法：你在电话中要怎么确认一个重要信息？

## 二、搭配爆破（10 分钟）

| 中文 | 英文 |
|------|------|
| 信号不好 | the line is breaking up / you're cutting out |
| 我没听清 | I didn't quite catch that. / Could you say that again? |
| 我稍后回复你 | I'll get back to you on that. |
| 长话短说（电话结束语） | I'll let you go. / I know you're busy. |
| 保持联系 | let's stay in touch / I'll keep you posted |
| 方便说话吗？ | is this a good time to talk? / did I catch you at a bad time? |
| 不好意思打扰了 | sorry to bother you / thanks for taking my call |
| 发个消息确认一下 | shoot me a message to confirm / I'll text you the details |
| 语音消息 | voice message / voice note |
| 我在开会，稍后打给你 | I'm in a meeting. Can I call you back? |

## 四、即兴表达（15 分钟）

**模拟任务**：你打电话给一家酒店，要：① 确认你的预订 ② 问能不能提前入住 ③ 问附近有什么好吃的餐厅。

一个人分饰两角，自己说完整对话。录音。

**准备**（1 分钟，提示词）：

Hi, I'm calling about... / Could you...? / Would it be possible to...? / Let me just confirm... / Great, thanks for your help. / I'll let you go. Bye!

**开始**：录音，完整对话应该 1-2 分钟。

**回听**：
- [ ] 开场说明了打电话的目的吗？
- [ ] 请求够礼貌吗？（不是"I want..." 而是 "Could you / would it be possible"）
- [ ] 结尾够自然吗？（不是突然挂断，而是"I'll let you go, thanks"）
- [ ] 听起来像是在"打电话"还是"读剧本"？

**修正**：把最不自然的那段重说 3 遍。
