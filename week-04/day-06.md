## 一、句型极速反应（15 分钟）

**规则**：每个场景，3 秒内说出回应。

### 电话/消息

| 场景 | 你的回应 | ✓ |
|------|---------|---|
| 打电话给对方，开场说明来意 | I'm calling about... | |
| 对方说的你没听清 | Sorry, I didn't quite catch that. Could you...? | |
| 需要跟对方确认信息 | Let me just make sure I got this right. So... | |
| 结束通话 | I'll let you go. Thanks for your time! | |

### 会议讨论

| 场景 | 你的回应 | ✓ |
|------|---------|---|
| 你想提出一个新观点 | I'd like to raise a point about... | |
| 你想接着别人的话往下说 | Building on what ___ said... | |
| 讨论跑题了，你想拉回来 | Can we circle back to...? | |
| 总结讨论内容 | So to recap... | |

### 面试

| 场景 | 你的回应 | ✓ |
|------|---------|---|
| 自我介绍 | My background is in... What that means in practice is... | |
| 讲你解决的一个问题 | One challenge I faced was... What I did was... The result was... | |
| 你的 5 年规划 | Where I see myself in 5 years is... | |

### 处理问题

| 场景 | 你的回应 | ✓ |
|------|---------|---|
| 先共情再说解法 | I understand... Here's what I can do: ... | |
| 你向别人反映问题 | There seems to be a problem with... Can we figure this out? | |
| 需要时间查一下 | Let me look into that and get back to you by... | |

### 社交场合

| 场景 | 你的回应 | ✓ |
|------|---------|---|
| 派对开场白 | How do you know [host]? / What brings you here? | |
| 顺着话题延展 | That reminds me of... / Speaking of... | |
| 优雅退场 | Anyway, I should probably... It was great talking to you! | |

## 二、即兴综合挑战（25 分钟）

**规则**：一口气完成 3 个场景。每个场景准备 30 秒，说 1-2 分钟。

**场景 1**：你在电话里跟酒店前台确认预订，发现日期订错了（你订的 7 月 15 日，应该是 7 月 16 日）。解决问题。

**场景 2**：你在一个行业活动的茶歇时间，主动跟一个陌生人聊天。了解 Ta 是做什么的、为什么来这个活动，顺便介绍一下你自己。

**场景 3**：你在一个小组讨论里，话题是"Should companies track employee productivity with software?" 表达你的观点，接着别人说的补充，最后做个简短总结。
